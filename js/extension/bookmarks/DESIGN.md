# 书签插件视觉规范

## 1. 方向

关键词：Pages 基线、克制、自用、搜索优先、结构清晰。

浏览模式必须保持白底、居中搜索、目录瀑布流和目录内纵向书签行。不得演变为侧栏、品牌区、后台顶栏或卡片仪表盘。

## 2. 表面语义

| 对象     | 默认             | 激活                | 边界       |
| -------- | ---------------- | ------------------- | ---------- |
| 固定结构 | 平面             | 不改变层级          | 单层边框   |
| 交互入口 | 安静、低存在感   | 阴影浮起            | 不加外描边 |
| 普通浮层 | 不存在           | 白色单层表面 + 阴影 | 不加外描边 |
| 模态     | 遮罩外的单层表面 | 模态阴影            | 外层不描边 |

边框表示固定范围，阴影表示正在交互，背景表示当前目标，间距表示结构。不得同时用外框、标题底、内容框和内阴影表达同一层级。

## 3. 浏览模式

- 页面背景 `#fff`，搜索带固定在独立滚动内容上方，使用克制向下阴影。
- 搜索区域水平居中；引擎入口与搜索框独立排版，不使用大胶囊、箭头或教学 placeholder。
- 书签部分左右使用 Pages 的宽边距，滚动条覆盖在最右侧，不占内容宽度。
- 目录为细边框圆角块，标题居中；目录内不为每条书签增加卡片边框。
- 目录标题约 36px，内容前距 10px；书签行和折叠占位为 48px，目录间距为 24px。
- 书签第一行显示 favicon + 标题，第二行显示从整行左缘开始的 URL。
- 标题 hover 只做轻微字号过渡，不改变行高、不裁字、不使用模糊缩放。
- favicon 使用浏览器缓存图像；加载失败显示稳定本地图标；书签 hover 保留旋转反馈。

## 4. 搜索下拉与引擎菜单

- 两者宽度和左边缘都锚定真实搜索框 DOM。
- 普通文本不显示搜索下拉；只有 `#` 和 `!` 显示。
- hover 使用浅中性背景，active 使用更明确的背景，selected 使用当前已确认背景；三者不可混为一色。
- 菜单不使用外描边、灰色标题底、二层卡片和原生焦点框。
- 搜索下拉和引擎菜单互斥，列表滚动槽不可占用内容宽度。

## 5. 工具与 tag

- 功能按钮、tag按钮位于搜索带最右侧，默认顺序为功能、tag，使用一致的低干扰图标和命中区。
- 功能与 tag 入口静止时只显示图标，不使用底板、边框或阴影；悬浮使用背景变化，功能组展开后由整组阴影表示激活。
- tag 面板搜索是单一组合字段；聚焦时高亮完整圆角容器，内部输入框不得出现第二层直角焦点框。
- 搜索带工具区使用独立绝对定位，不参与搜索框居中和宽度计算。tag 固定在最右侧，功能按钮在其左侧；悬浮命令继续向左展开，展开前后两个入口和搜索框均不得位移。
- 悬浮后以一个统一阴影表面展开；单个命令不叠加边框或阴影。
- 点击命令立即执行并关闭；需要输入的动作进入模态。
- 不显示 Logo、说明、工具文字和重复 tooltip。

## 6. 整理模式

- 整理模式仍是同一页面，沿用搜索、字体、颜色和目录风格。
- 工具条为固定模式结构，只保留一层边界；目录/书签选中使用背景，不套嵌套边框。
- 整理模式-书签使用自然高度和保序布局；拖动时目标目录、预测槽和插入线清晰可见。
- 整理模式-目录使用等高 Grid；拖动副本脱离 Grid，唯一预测槽占据实际落点。
- 不使用“完成”、复制 URL、空内容占位或难以区分的上下箭头。

## 7. 模态

- 遮罩 + 单一白色表面 + 统一模态阴影。
- 标题、正文、footer 通过间距组织，不使用独立背景和分割线。
- 只有输入字段和必要固定范围使用边框。
- Select、Combobox、TagsInput 菜单是无描边普通浮层，并且层级高于模态。

## 8. 字体与响应式

```css
font-family: '等距更纱黑体 SC', 'Sarasa Mono SC', 'mononoki regular', 'Consolas', monospace;
```

- 页面不得横向滚动。
- 列数随可用宽度降低，窄屏至少保持单列和搜索可用。
- 工具、搜索下拉和模态不得遮住关键内容或互相重叠。

## 9. 视觉阻断项

出现以下任一项即不通过：浏览模式固定侧栏、Logo/说明、后台式顶栏、目录横向卡片、书签密集边框、favicon 全部灰色占位、hover 图标不旋转、无 extra 数据伪造 tag、整理画布影响浏览模式。
