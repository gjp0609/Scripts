# 书签插件视觉与交互设计规范

## 1. 设计结论

浏览态应当像用户长期使用的 Pages 单页面，而不是重新设计成后台管理器。

一句话标准：

> 白底、居中搜索、结构性留白、目录瀑布流、目录内宽松纵向书签行，管理能力退到第二层。

## 2. 视觉基线

主基线：

- Pages 页面：`R:\Files\Workspace\Mine\pages\docs\single\bookmarks\index.html`
- Pages 样式：`R:\Files\Workspace\Mine\pages\docs\single\bookmarks\style.css`
- 用户期望截图：`R:\Files\Data\ScreenShot\PixPin\Auto\PixPin_20260729_152618.png`

反例：

- `R:\Files\Data\ScreenShot\PixPin\Auto\PixPin_20260729_152732.png`

反例的问题不是单个控件，而是整体风格错误：固定侧栏、后台式顶栏、蓝色主操作、过密分隔线、左对齐目录工具头和全宽填满内容，使页面从“个人书签页”变成“管理后台”。

`tmp/*.html` 只可参考表单状态和功能覆盖，不再作为浏览态视觉来源。

## 4. 页面与搜索区域

### D-001 页面背景

- 浏览态主背景为白色。
- 不使用大面积浅灰后台底色。
- 不使用渐变、玻璃拟态、品牌色铺底或装饰图形。
- 留白来自内容边距和搜索区域，不来自放大卡片间距。

### D-002 搜索带

Pages 参考值：顶部约 `2rem`、底部约 `1rem` 内边距，搜索带下方留出约 `2rem` 呼吸区，并用低对比灰色阴影与内容分开。

- 搜索组合整体水平居中。
- 搜索框桌面宽度约 `30rem`，高度约 `3rem`，胶囊形细灰边框。
- 搜索引擎位于输入框左侧，是小型图标 + 名称，不是占满顶栏的下拉区域。
- 不在同一行常驻浏览/整理 tabs、Logo、说明和多枚主按钮。
- 默认焦点清晰但克制，边框轻微加深即可。

### D-003 搜索浮层

- 与输入框左边和宽度严格对齐。
- 桌面宽度约 `30rem`。
- 白底、约 `0.5rem` 圆角、低对比灰色阴影。
- 结果行以标题和次级 URL 为主，不做卡片套卡片。
- 高亮使用中性浅灰；主色只能作为焦点细节。
- 内容多时内部滚动，不撑破视口。

搜索浮层有四种互斥内容状态：

- 普通结果：网络搜索动作在首行或尾行保持稳定位置，书签结果显示标题与 URL。
- 叹号目标：显示 `search` / `search_site` 目标及类型；筛选词和真正搜索关键词在视觉上可区分，但不增加第二个输入框。
- tag 候选：输入 `#` 后显示匹配的 tag 名称、书签数量和搜索能力标记；候选高亮与键盘选择规则和普通结果一致。
- 空状态：一句紧凑说明和可选的“配置搜索目标”次级入口，不出现大面积插画或功能教学。

`search`、`search_site` 不作为普通内容标签展示。

### D-004 左侧 tag 面板

- 只有存在真实 tag 时才显示入口；入口位于内容区左缘，是紧凑的标签图标按钮和 tooltip，不显示文字 Logo、说明或彩色导航点阵。
- 点击入口后在其右侧展开约 `240px` 的悬浮面板；面板覆盖内容边缘但不改变瀑布容器宽度，因此不触发 Macy 重排和目录跳动。
- 面板使用白底、细边框和低对比阴影；顶部只有“标签”、关闭按钮和紧凑过滤输入，列表显示 tag 名称与书签数量。
- tag 行是单选命令项，不使用复选框或独立 token；hover、键盘焦点和与当前 `#tag` 完全同名的项具有一致的中性高亮。
- 点击 tag 后悬浮面板立即关闭，搜索框内容变为 `#tag`，主搜索浮层也保持关闭，焦点回到搜索输入框。
- 面板只改搜索框文本，不直接改主内容过滤状态；精确匹配由同一个查询解析器得出，使鼠标与键盘始终共享同一状态机。
- 点击面板外、再次点击入口或按 Esc 关闭；关闭动画短且克制，不保留遮挡点击的透明层。
- 窄屏沿用相同悬浮逻辑，但面板宽度受 `calc(100vw - 2rem)` 限制，不能覆盖关闭入口或造成横向滚动。

## 5. 目录瀑布流

### D-010 容器

Pages 参考值：内容左右边距为视口的 `5%`，窄屏降为固定小边距。

- 桌面使用 Macy 类真实瀑布布局。
- 约 1920px 视口呈现 4 列；中等桌面按宽度降为 3 列或 2 列。
- 目录按浏览器顺序进入布局，重排后顺序可预测。
- 搜索、折叠、数据同步和 favicon 完成后不产生重叠。

### D-011 目录块

Pages 参考值：宽约 `25rem`、细灰边框、约 `1rem` 圆角、块间距约 `1rem`。

- 目录块本身是信息容器，不再给内部每个书签加独立卡片边框。
- 目录头浅灰底、标题居中、细底边。
- 浏览态默认只显示目录名称。
- 数量、目录图标、箭头和管理按钮不得同时挤占标题行；确有需要时以 hover、tooltip 或整理态呈现。

## 6. 书签行

### D-020 尺寸与排版

Pages 参考值：每行约 `3rem` 高，内容区比目录块左右各缩进约 `2rem`。

- favicon：约 16px，无底板、无边框。
- 标题：约 16px，常规或中等字重，单行省略。
- URL：标题下方，约 10px，灰色，单行省略，保留协议和完整路径的可见开头。
- 行间不使用当前反例中的密集横向分割线。
- 没有标签和备注时不保留空白槽位。
- 有标签时默认不应改变所有行高；可在 hover、编辑或筛选入口中使用。

### D-021 hover 与焦点

- hover 时标题只做轻微字号或颜色变化，不抬升整张卡片。
- favicon 在书签行 hover 时以约 3 秒线性周期旋转，这是 Pages 已有反馈。
- favicon 加载状态可以有轻量 spinner，但不能替代 hover 旋转。
- 键盘焦点应可见，且不能造成布局位移。
- 有备注时 hover 和键盘焦点可访问备注提示。

## 7. favicon 设计

### D-030 来源与加载

- Chrome / Edge 首选浏览器扩展原生 `/_favicon`，读取浏览器已有缓存。
- 同一 URL / 域名复用结果，避免重复加载。
- 初始化不能对全部书签逐个访问网站或公共 favicon 服务。
- 原生缓存失败时使用本地默认图标；网络降级必须单独控制。
- 图片加载完成前保持 16px 稳定占位，不能让文字左右跳动。
- 图标失败不显示破图标记。

### D-031 刷新

- 手动刷新只在整理态或低频菜单中出现。
- 刷新按钮与 favicon 显示忙碌反馈。
- 刷新单项不能让其他行图标闪烁或整个瀑布重建。

## 8. 管理能力的视觉位置

### D-040 浏览态工具

新增、目录、全局折叠、整理、设置都属于次级工具。

- 使用紧凑图标按钮，固定在不遮挡内容的位置，配 tooltip。
- 可组合为右下角竖向工具组或一个展开式工具菜单。
- 不能使用固定左侧栏。
- 不能让蓝色大按钮成为首屏最强视觉元素。
- 全部展开 / 收起应使用明确图标状态，不占一条导航项。

### D-041 整理态

- 整理态是同一页面的工作状态，不切换成后台式新页面；搜索带、内容宽度、字体、颜色和目录结构继续沿用浏览态。
- 进入后出现一条紧凑工具条：退出整理、目录 / 书签分段控制、新增、撤销和必要的低频菜单。工具条不能盖住搜索框或另起品牌顶栏。
- 进入时以当前视口中的目录或书签作为滚动锚点；布局切换后将锚点恢复到接近原位置，避免跳回顶部。
- 搜索文本和 tag 筛选可保留在输入控件中，但整理画布必须展示完整书签结构，并以弱化提示说明“整理时显示全部”。

目录整理：

- 所有目录临时收缩为稳定高度的紧凑块，只显示目录名、数量、拖拽把手和低频目录操作。
- 不显示书签拖拽把手、书签编辑和删除按钮。
- 被拖动目录保持固定宽高；原位留占位，候选插入位置使用清晰竖线或块间槽，不依赖卡片漂浮阴影表达。
- 完成、取消或切换子模式时恢复进入前折叠状态；回到浏览态后重算 Macy。

书签整理：

- 目录保持完整容器，目录头不作为拖拽源；每行只增加一个稳定宽度的拖拽把手和一组 hover / focus 操作。
- 拖动项降低不透明度但文字仍可辨认，原位置保持等高占位，插入位置使用贯穿内容宽度的细线。
- 跨目录时只高亮实际接收目录，空目录也必须具有稳定的可放置高度；无效区域使用 `not-allowed` 光标和克制的错误色边框。
- 靠近可滚动区域上下边缘时平滑自动滚动，速度随距离递增，但不得突然跳屏。

写回与退出：

- 放下后被移动项和相关目录显示局部忙碌状态，其他目录仍可浏览；同一对象的重复动作暂时禁用。
- 成功后插入线消失并短暂显示局部成功状态；失败后动画回到原位置，恢复数据和 DOM，并在原操作附近提示原因。
- 撤销可通过工具条图标和 `Ctrl/Cmd+Z` 触发；按钮文案或 tooltip 应说明将撤销哪一次移动。
- `Esc` 优先关闭菜单 / 弹窗或取消当前拖拽；没有局部浮层时才退出整理态。存在写回中的操作时，等待结果后再退出，不能静默丢弃状态。
- 退出后所有管理控件退场，恢复进入前的搜索、tag 筛选、滚动锚点与 Pages 式浏览布局。

### D-042 弹窗与 Popup

- 弹窗、菜单和 Popup 使用白底、细边框、低对比阴影。
- 卡片圆角不超过 8px，除非是 Pages 原有目录块。
- 危险操作以文字、图标和局部状态表达，不使用大面积警示装饰。
- Popup 是窄幅操作面，不照搬主页瀑布布局。
- 编辑模式使用成熟组件库的 Dialog、Form 控件、Select、Combobox 和 TagsInput，不继续维护手写 backdrop、焦点圈、目录下拉和 tag 建议列表。
- 组件采用无样式或可完全覆盖主题的模式，仅复用交互、无障碍和定位能力；最终外观仍使用 Pages 的白底、细边框、紧凑间距，不能变成组件库后台表单。

### D-043 tag 输入控件

- tag 字段是一个多行自适应的 token 容器，最小高度与普通输入框一致；token 增多时向下换行，不横向撑破弹窗。
- 已选 token 使用中性浅灰底、细边框和小型移除图标；`search`、`search_site` 使用“搜索能力”文字标识，而不是强烈警示色。
- 建议浮层与输入容器同宽，最大高度受视口限制；每项显示 tag 名称和使用次数，已选项显示勾选但不可重复添加。
- 建议分为“已有标签”和“搜索能力”两组；没有完全匹配时，“创建新标签”作为最后一项，避免误触。
- 选择 `search` 后在 tag 字段下方就地展开搜索模板输入和占位符校验；选择 `search_site` 后只显示解析出的目标域名预览。
- 校验错误显示在对应字段下方，不使用全局 toast 代替表单错误；保存失败后保留所有输入和焦点上下文。

## 9. 字体与颜色

### D-050 字体

首选：

```css
"Sarasa Mono SC", "等距更纱黑体 SC", "Consolas", monospace
```

所有主页文本统一使用该字体栈。不要混入系统无衬线字体造成行高和字宽跳变。

### D-051 色彩

- 页面：`#ffffff`。
- 目录头：约 `#f5f5f5`。
- 主文字：接近 `#111111`。
- 次级 URL：灰色。
- 边框：接近 `#cdcdcd`，使用细线。
- hover：中性灰或极弱强调色。
- 主色只用于焦点和命令确认，不主导页面。

## 10. 响应式

- 大桌面优先忠实还原 Pages。
- 目录列数随可用宽度降低，最窄为单列。
- 小屏搜索框可缩短，但仍保持搜索优先。
- 工具按钮不得与搜索框重叠。
- 页面不得横向滚动。
- 文本必须在容器内省略或换行，不得遮挡相邻元素。

## 11. 视觉阻断项

出现任一项即不得判定设计通过：

- 浏览态存在固定侧栏。
- 浏览态出现 Logo / 产品说明。
- 浏览态主要结构是后台式固定顶栏。
- 目录占整行，内部书签横向排卡。
- 目录标题左对齐并被图标、计数、箭头和操作按钮包围。
- 每个书签都有明显边框和密集分割线。
- favicon 默认是统一灰色图标而非浏览器缓存图片。
- hover favicon 不旋转。
- 无 extra 的导入数据出现伪造标签或快捷搜索配置。
- 自动化小夹具好看，但真实 214 条数据与 Image #1 的整体气质明显不同。

## 12. 视觉验收方法

至少保存并人工对照：

- 真实 214 条书签，约 1858x1005 视口，和 Image #1 并排比较。
- 搜索框聚焦状态。
- 普通搜索结果浮层。
- `!` 快捷搜索在有目标和无目标数据下的状态。
- 单目录折叠和全部折叠。
- favicon 已加载、加载失败、hover 旋转和手动刷新。
- 整理态桌面截图。
- 390px 窄屏截图。

最终视觉通过必须包含用户真实数据确认，不能只依赖 Playwright 断言。
