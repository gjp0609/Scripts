## 最近记录

### 当前轮：修正搜索浮层宽度与定位

- 用户临时需求：`search-overlay` 和 `quick-overlay` 出现偏移，且宽度与搜索框不一致。
- 已确认原因：旧实现使用静态 `calc(...)` 定位和固定 `440px` 宽度，没有绑定真实搜索框 DOM 尺寸。
- 已执行：改为运行时读取搜索框的 `getBoundingClientRect()`，让两个浮层跟随真实搜索框的左边界、顶部和实际宽度。
- 已验证：`npm run build` 通过，WXT 构建成功。
- 遗留问题：仍需用户在真实浏览器里确认视觉对齐是否与设计稿一致。

### 当前轮：修正搜索浮层定位

- 用户临时需求：`search-overlay` 和 `quick-overlay` 与搜索框没有对齐。

- 已确认补充问题：浮层宽度仍沿用旧的 `440px`，与真实搜索框宽度不一致。
- 准备执行：将两个浮层改为跟随真实搜索框的运行时定位，并直接使用搜索框实际宽度。
