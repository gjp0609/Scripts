# 书签插件回归矩阵

测试分为纯函数、组件交互、真实扩展和用户视觉确认四层。自动化通过不能替代真实书签页面验收。

## 1. 每次变更必测

| 编号 | 场景 | 结果 |
| --- | --- | --- |
| B-01 | 默认打开浏览模式 | 搜索框聚焦，Pages 结构无 Logo/侧栏 |
| B-02 | 普通文本输入 | 只过滤书签部分，无搜索下拉 |
| B-03 | `#` 输入、hover、上下键、Enter | 候选 active 一致，精确筛选正确 |
| B-04 | `!` 输入与执行 | 仅 `search_site` 目标，当前引擎可见 |
| B-05 | 引擎菜单 | selected/active/hover 可区分，与搜索下拉互斥 |
| B-06 | 全局直接输入 | 首字符进入搜索框，表单和输入法不被截获 |
| B-07 | 单目录与全部展开/收缩 | 48px 网格、24px 间距、Macy 无重叠 |
| B-08 | Esc 连续按下 | 每次只退一层，最终恢复浏览默认状态 |
| B-09 | favicon | 缓存图、占位、旋转和全量刷新行为正确 |
| B-10 | 桌面和窄屏 | 无横向溢出，滚动条不挤内容 |
| B-11 | `!` 模式主体 | 不显示普通书签搜索结果，但保留书签部分背景和当前引擎入口 |

## 2. 浏览模式保护矩阵

改动整理模式或公共样式后必须执行：

| 编号 | 检查 |
| --- | --- |
| BR-01 | 白底、居中搜索、目录瀑布流、目录内纵向书签行 |
| BR-02 | Macy 为最短列优先，真实目录高度变化后无残留旧坐标 |
| BR-03 | 目录边框相位只出现 0/24px，折叠与展开下方边框对齐 |
| BR-04 | 标题 hover 清晰、不模糊、不裁字、不拉高行 |
| BR-05 | favicon 缓存图覆盖占位，hover 旋转，全量刷新不整页闪烁 |
| BR-06 | 浏览模式没有拖拽、编辑、删除、目录计数或整理工具条 |
| BR-07 | 搜索带阴影、主内容覆盖式滚动条和左右边距一致 |
| BR-08 | 退出整理后恢复全部 BR-01 至 BR-07 |

## 3. 整理模式-书签

- 搜索和 `#` tag 过滤仍有效。
- 整理模式-书签普通文本按书签字段过滤；整理模式-目录普通文本只按目录标题过滤。
- 空目录和收缩目录始终保留一行无边框、无文字的稳定投放区，拖动开始时整体高度不跳变。
- 同目录、跨目录和筛选状态下的落点与完整顺序一致。
- 收缩目录平时无 `...`，保留稳定投放区；接近目标时动态展开真实列表。
- 拖动期间滚轮、边缘自动滚动、取消和无效区域均正确。
- 编辑更换目录后位于目标目录尾部。
- 删除书签有效，失败不丢数据。
- 整理模式没有撤销按钮，也不接管 `Ctrl/Cmd+Z`；失败移动重新加载真实数据。

## 4. 整理模式-目录

- 进入后目录始终只显示等高标题，使用正常流 Grid，无展开/收缩按钮。
- 搜索只过滤目录，不能加载书签拖拽实例。
- `#` 查询命中目录内书签时保留所属目录；普通文本不因书签内容命中而显示目录。
- 拖动副本脱离 Grid，Grid 只有一个预测槽。
- 指针进入目标卡片任意位置时，预占位立即占据目标原槽位，不设置前后半区阈值。
- 指针停在预测槽上时顺序稳定，不反复换位或闪烁。
- 视觉预测顺序与 Chrome 最终顺序完全一致。
- 根目录混有直属书签时绝对索引仍正确。
- 源目录向前或向后移动时，预测槽与 Chrome API 最终位置一致。
- 目录删除有效，失败保留原状态。

## 5. 模态、Popup、备份

- 添加/编辑书签、目录保存和失败保护。
- tag 补全、新建、去重、粘贴拆分、输入法和互斥保留 tag。
- 删除确认、Esc 层级和整理模式保留。
- Select/Combobox 菜单位于模态之上。
- 导出递归包含根直属书签、嵌套目录、嵌套书签、extra 和偏好；无效导入零修改。
- 导出 JSON 为 v3，包含导出实例标识；同实例恢复按 sourceId 找回移动节点，跨实例首次按父目录结构和重复项顺序匹配；持久化每个源节点到真实 Chrome ID 的映射，删除原节点后连续导入同一备份不生成副本；折叠目录和自定义引擎恢复为目标 ID，内置引擎 ID 不变。
- 导入只 patch 备份涉及的 extra；导入期间 Popup 或其他页面写入无关书签 extra 时，该数据不得被覆盖。
- storage 写失败时新增/编辑书签有补偿恢复；编辑保留 faviconOverride；连续双击保存、删除和 Popup 保存不会重复执行。
- 主页面、Popup 和后台同时写入不同 extra 或偏好字段时，不会因整对象覆盖丢失另一方更新；普通读取不触发隐式清理。
- 在浏览器书签管理器中将一个已有内容的目录移入书签栏，当前页面应一次显示完整直属书签，不出现临时空目录。
- Popup 读取当前页、选择目录、成功关闭、失败保留。
- 编辑书签和目录验证关闭、取消、遮罩三条鼠标退出路径；非忙碌导入导出验证关闭和遮罩；危险删除验证关闭和取消，并确认遮罩不会关闭。

## 6. 工具与命令

- tag按钮悬浮/点击/键盘打开，点击 tag 等价于输入 `#tag`。
- 功能按钮默认收缩，悬浮展开为单一阴影表面。
- 全部展开、全部收缩、刷新图标、添加、整理和备份命令执行后状态明确。
- 没有完成按钮、复制 URL、冗余提示和错误方向图标。
- 整理工具条可用鼠标“退出整理”立即回到浏览模式，结果与无更高交互层时按 Esc 一致。
- 功能菜单命令首次点击即可稳定命中；引擎菜单和 tag 面板可用真实指针连续移入并选择。

## 7. 自动化门槛

```text
npm run typecheck
npm run test
npm run build
```

真实扩展测试必须覆盖：真实 Chrome MV3、浏览器书签 API 写回、外部事件、Macy、Sortable、favicon、Popup、桌面和窄屏。所有测试应记录数据夹具、浏览器 profile、截图和控制台错误。

## 8. 用户最终确认

用户必须使用自己的真实书签数据确认：

- 默认浏览模式整体风格与 Pages 一致。
- 搜索、tag、`!`、引擎和 Esc 不增加操作层级。
- 整理模式两个子模式的预测落点和最终结果一致。
- 图标、滚动条、目录高度和标题布局没有视觉退化。
