# 开发浏览器数据

WXT 开发模式使用此目录保存可复用的浏览器 profile：

- `chromium/`：Chrome、Chromium 或 Edge 的开发数据。
- `firefox/`：Firefox 的开发数据。

浏览器首次启动时会自动创建对应目录。扩展的 IndexedDB、设置、测试历史和页面状态会在开发浏览器关闭后保留，便于开发者与验收人员复用同一份本地状态。

这些 profile 可能包含浏览记录等隐私数据，除本说明外的全部内容均由 `.gitignore` 排除，不得提交。使用同一 profile 启动下一次开发会话前，应先关闭上一次开发浏览器，避免目录被浏览器锁定或数据损坏。
